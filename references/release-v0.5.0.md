# v0.5.0：Skill 直接查询公开 GitHub 知识库

日期：2026-11-05。

用户没有云服务账号，并选择暂不走 MCP。此版默认改成 Skill 在客户端按需读取维护者的 GitHub 数据，由用户正在使用的 AI 理解、重排、补查和回答。公开 MCP 保持原状态，本次未升级或新建云端服务。

## 本版行为

- 普通入口直接走 GitHub，不先探测 MCP。已有维护者本地配置和环境变量不改变默认知识库；只有显式本地参数才读本地库。
- 仅需现有 Python 3.11+ 标准库，无账号、API Key、MCP SDK、向量模型或手工导入。
- 固定版本快照含 983 份文档、6,567 个检索片段；每次只读取需要的索引与原文，每数据版本最多缓存 32 MiB。
- 默认执行 AI 改写后的关键词多子查询、融合去重和原文回读。最多 6 条明确子查询优先保留，避免后一个平台或子问题被自动扩展词挤掉。
- 语义采用范围与草稿检查串成可执行流程；日期、产品模式和样本不能在润色时丢失。联网补充与库内材料分开标注。
- 神经向量默认未启用。维护者已有本地模型和索引功能保留为显式选项，不冒称公开三路模型服务上线。
