# v0.5.1：安装后读取内置答题规则

日期：2026-11-05。

用户只需提供一句带仓库地址的安装指令，后续直接问海外 GEO 问题。此版将原来分散在长提示词里的要求放入 Skill 的入口、答题规则与安装接入说明。

## 改动

- SKILL.md 指定首次加载要读的规则，增加安装接入、后续触发及默认答题约定。
- answer-guide.md 明确如何匹配问题、核查当前信息、按样本解释、给小白讲解和附来源。
- README 与 usage-prompt.md 的安装指令缩为一句；安装助手需要真正读取规则并验证检索回读，用户不用准备资料或配置 MCP。
- agents/openai.yaml 保留允许自动调用，默认提示指向内置规则；它不是所有客户端通用的自动安装钩子。
- Skill 包版本为 0.5.1；检索执行引擎仍为 0.5.0，故命令 JSON 的引擎 version 保持 0.5.0。没有修改检索算法、数据快照或公开 MCP。

## 本轮实际检查

1. skill-creator 的 quick_validate 检查通过。
2. 既有 test_entry.py 六项与 test_geo_workflow.py 两项测试全部通过，使用现有 Python、`-S` 标准库环境。没有安装额外依赖。
3. 按安装说明运行 status，实际通道为 github_snapshot，未连接 MCP。
4. 安装示例查询实际执行两条关键词查询，返回来自 13 份文档的 16 个候选片段，16 个片段回读完成；来源完整性校验通过。读取了实际片段以检查回读内容，并未把这些候选全部视为事实证据。
5. 本轮复查修改文档与引用路径、git diff 格式及发布清单哈希。

这些检查确认入口和资料回读可用，不等于全部候选对题、所有结论正确或新客户端一定自动加载。未进行豆包等外部客户端的实际安装演示，也未将上一轮 Claude/Grok 答案冒充本轮重测。

## 使用边界

客户端需要真实支持 Skill、脚本执行与网络访问；必要时重新加载。当前变化信息在答题时联网核查原始来源，明确数据时间；没有新证据就保留历史范围。知识库是固定版本快照，不承诺与 Obsidian/飞书实时同步或所有答案永远最新。
