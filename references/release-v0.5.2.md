# v0.5.2：补齐资料并定位真正回答问题的段落

日期：2026-11-05。Skill 与执行引擎版本均为 0.5.2。默认直接查询公开 GitHub 快照，不配置 MCP，也不要求安装者导入资料。answer-guide.md 与 evidence-policy.md 保持 v0.5.1 内容，继续使用用户认可的中文讲解方式。

## 改动

- 固定快照更新为 987 份文档：986 份内容、1 份导航；6603 个可检索片段。原有983份正文版本全部保留，补入4份遗漏正文。
- 补回565个原文已有的来源链接、335个明确完整发布日期。未知字段仍未知；出版、更新、观测、收录和核查时间分开保存，不用文件修改时间代替发布日期。
- 新增可重复的源库扫描和派生清单，记录新增、正文变化、排除与待分类候选，避免只沿用旧映射而遗漏新资料。
- 标题、作者/机构、来源URL、ID先定位文章，再在文章中按实际问题寻找段落。支持指定文档版本及行范围搜索，提供分页和上下文读取入口。
- 修复标题中的平台承接、来源名称被主题词挤掉、拉丁词边界，以及前言/目录抢占长词典正文的问题。检索仍是词法与结构定位，语义判断仍由当前AI完成。
- 同一论文的出处页、学习笔记和全文可导航；导航不能升级为回答证据，同源资料不重复计成独立来源。
- 逐条断言核对官方来源平台，补齐 Copilot、Google AI Mode/Overviews 的官方域名归属；跨平台问题不能以一方官网支撑另一方事实。
- 提供1208个内容去重后的图片/PDF公开链接，共359,037,561字节。1588处本地引用已解析，35处外站引用保留外站，缺失与歧义均为0。附件按需打开，安装不下载整套媒体，未读取附件不声称看过图表。
