# v0.4.0：检索匹配与小白问答验证记录

验证日期：2026-11-05。此记录只陈述实际运行范围，不表示任意 AI 客户端或任意问题都不会出错。

## 改了什么

- 点名平台时，候选片段必须包含该平台，并检查是否存在与问题有关的描述。使用 Claude 写 SEO 的教程、建议推出 Grok 搜索的帖子，不再充当“平台实际信源”的直接候选。
- 多平台问题分别保留候选；未点名的海外 AI 比较题明确展示示例检索范围，不冒充完整产品名单。信源分类、操作、统计与训练问题保持区别。
- 官方资料笔记优先，背景另列；所有候选仍需要回读和语义判断。
- 回答先直接讲明白，再给必要解释、教学例子与结论对应的依据。有限检索不能声称读完全库；接通服务不能声称答案已审核。
- 原文结束行超过正文时按实际末行返回，避免把短文章的读取误报成网络失败。

## 回答内容核对

实际回答分别说明 Claude 的网页搜索/网址读取与 Grok 的公开 X/网页渠道。Claude 的具体网站例子仅归因为 2025 年论文的相应行业实验，保留模型、问题类型和日期，不改写为当前固定排名；Grok 的偏好证据不足时保留具体缺口。

回答中的关键断言均保存了采用版本、连续摘录与行号，并重新在固定源文件中定位。维护者还对照了论文 v1 的 [5.2.2 节](https://arxiv.org/html/2509.08919v1)中消费电子、汽车来源名单，确认未把旁边 GPT 的名单移给 Claude。核对摘录和阅读语义不等于重新进行论文实验或独立专家审核。
