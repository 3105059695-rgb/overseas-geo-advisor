## Grok 的 X 来源检索

官方开发文档说明，X Search 允许 Grok 在 X 上做关键词搜索、语义搜索、用户搜索和帖子串读取，从实时社交内容中提取信息。这里的“语义搜索”可以理解为按意思找内容，不仅匹配完全相同的词。

## 原文短摘录

> keyword search, semantic search, user search, and thread fetch

## 给小白的解释与边界

教学例子：想查某个公司刚发布的消息，可以把公开账号、帖子和相关回复当作待核对的来源。能搜索帖子不代表每条帖子都会被采用，也不代表点赞数就是引用排名。本页介绍工具能力，没有给出各账号、网站或内容类型的固定偏好比例。
